# Pulse Wallet

Full-stack digital-wallet project built using HTML, CSS, JavaScript, and Node.js.

## Run

1. Run `npm start` in this project folder.
2. Open `http://localhost:3001`.

Demo account: `ranjit@example.com` / `wallet123`

## Features

- Login
- Persistent wallet balance and activity
- Add money and send money
- Add payment cards
- Monthly spending view

The local `data/wallet.json` file acts as the demo database. This is educational code, not a production payment system.
